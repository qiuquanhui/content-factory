## 实测中修复

- 上游牛客源可能返回无 ID/URL 的未支持类型，过滤后修复完整类型检查。
- 上游 React 19 的 `useRef` 初始化类型与 ESLint 配置导出类型问题。
- 将源级取消信号传至实际 HTTP 请求，抖音临时 Cookie 请求也纳入超时约束。
- 避免重新读取缓存就更新平台成功时间；应用直接记录真实采集观测。
- 中断任务在重启时优先重试，避免因旧采集时间被周期判断跳过。
- 切换筛选时保持概览稳定，同时在新结果返回前展示加载状态，避免把旧列表冒充新筛选结果。

## 实现范围与限制

- 这是可运行的选题阶段：写作模型、作者风格学习与平台文章发布尚未接入，仅提供明确的适配器契约和稳定选题 ID。
- 定时任务需要应用进程持续运行；机器关机或休眠时不运行。
- 默认单实例、本机访问。没有实现多用户、分布式任务协调或公网账号体系。
- 真实平台首轮已成功，不能保证源永久可用；系统会记录并展示失败、保留旧数据及按周期重试。
- 未执行 Docker 镜像构建、30 天时间跨度的真实运行或长期稳定性压测。保留期与调度边界通过可控测试验证。
- Node 24 内置 SQLite 在当前运行时仍会输出 experimental 提示；本次构建与运行测试均已通过。

## 快速验收

打开 `http://127.0.0.1:3000`，依次尝试：筛选一个关注主题 → 收藏一条热点 → 加入选题 → 在“我的选题”导出 JSON → 在设置中修改关键词。无需模型密钥或发布账号。

原始 HTTP 验收记录写入本地 `.data/smoke-report.json`，运行时数据位于 `.data/content-factory.sqlite`。保留本地数据库目录即可持续积累选题。
