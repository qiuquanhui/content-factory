## 推荐决策

有条件首选 **NewsNow 的固定版本二次开发**，沿用 TypeScript、React、Nitro/H3 和 SQLite。在现有平台采集器之上增加标签筛选、无人值守调度、持久化历史和选题收藏，并将首页简化为一个热点列表。

主要理由：已有前后端和采集器，可以在一个应用内完成阶段一，避免另建采集服务、Java 后端和前端三套工程。当前工作区检查结果为空，未发现已有代码、技术栈约束或适用的 AGENTS.md。用户消息使用了 Java 代码块，但未明确要求 Java 技术栈，因此本建议仍需确认。

主要限制：NewsNow 已公告将推出 NewsNext，停止接受外部贡献；虽仍有近期修复，但后续维护不能完全依赖上游。目标平台也尚未在用户实际运行网络中测试。本次没有启动应用、安装依赖或执行采集，不能据此认定六个平台已全部可用。
