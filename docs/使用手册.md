# 使用手册

## 日常操作

1. 按项目首页启动服务，打开 [工作台](http://127.0.0.1:3000/)。
2. 在“我的关注”浏览 AI 主题相关热点；“全部热点”包含未匹配主题的已采集内容。
3. 使用主题、平台、时间筛选或搜索框缩小范围。搜索只查询已采集到本地的数据。
4. 点击标题打开来源页面；点击书签收藏；点击“加入选题”放入“我的选题”。
5. 在“我的选题”下载 JSON 资料，包含标题、链接、来源、匹配信息和稳定的选题 ID。

“收藏夹”用于保留灵感，“我的选题”表示准备创作。二者独立，可以只收藏、只选题，或同时使用。点击“已加入”可将尚未进入创作阶段的选题移回热点池。

## 关注主题

点击“管理关注”或“设置 → 关注主题”。默认提供 AI 大模型、AI 工具、AI 商业、AI 创作四个主题。

- 关键词用逗号分隔，命中任意一个即可匹配。
- 排除词优先，仅排除当前主题的匹配，不影响其他主题。
- 支持最多 20 个主题；每个主题最多 30 个命中词和 30 个排除词，每词不超过 60 字。
- 主题名称为 1–30 字。禁用或删除主题不会删除收藏和已选题内容。
- 保存修改后，已有内容会重新匹配，不用等待下轮抓取。

例如：主题“AI 编程”，关键词 `Cursor、Codex、Copilot、AI 编程`，排除词 `卖课、培训广告`。

匹配使用标题和来源自带的可选摘要；中文按子串匹配，英文/数字词按边界匹配，忽略大小写并做全半角归一化。`AI` 不自动等于 `OpenAI`，需要分别配置。当前没有语义推断或大模型筛选。

## 来源与刷新

“设置 → 数据来源”可启停平台，查看条数、最近成功时间和失败原因。默认每 10 分钟一轮，可在“采集设置”改为 30/60 分钟。

手动“刷新热点”会合并正在执行的任务，并尊重每个平台的最小请求间隔；刚抓过的平台可能跳过。关闭网页不影响后台，关闭服务或机器休眠会停止采集。

## 如何理解列表

| 字段 | 含义 |
| --- | --- |
| 行号 | 当前列表的展示序号 |
| 榜单 #N | 该热榜源返回列表中的位置，不是跨平台热度分 |
| 资讯 #N | 资讯/RSS 返回的条目顺序，不代表官方热榜 |
| N 分钟前观测 | 本应用上次采集到该内容的时间，不是文章发表时间 |
| 历史数据 | 来源当前采集失败，展示的是上次成功数据 |
| 已离榜 | 最近成功结果或空榜中已不包含该条目 |
| 主题标签 | 鼠标停留可查看命中的关键词 |

默认按发现时间窗口交错展示各来源。普通列表可查近 24 小时、7 天、30 天；收藏和已选题内容不受这个时间窗口限制，但仍受你选择的主题、平台和搜索条件影响。

## 当前能力范围

自动写作、作者风格学习、多平台文章发布是后续阶段，当前尚未启用。“创作流程”中明确展示这些阶段的状态。现在无需模型密钥或发布账号。
