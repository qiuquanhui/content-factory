# 数据源说明

当前配置 10 个来源，定义位于 `shared/content-factory.ts`，适配入口位于 `server/services/content-factory/providers.ts`。

| 来源 | 源 ID | 采集方式 | 内容 |
| --- | --- | --- | --- |
| 微博 | `weibo` | 热搜页面解析 | 实时热搜 |
| 知乎 | `zhihu` | 平台热榜接口 | 热榜条目，当前适配器请求 20 条 |
| 百度 | `baidu` | 热搜页面解析 | 实时热搜 |
| 今日头条 | `toutiao` | 平台热榜接口 | 热榜事件 |
| 抖音 | `douyin` | 临时 Cookie + 平台热榜接口 | 热榜词条 |
| 哔哩哔哩 | `bilibili-hot-search` | 热词接口 | 热搜词，不混入视频榜 |
| Hacker News | `hackernews` | 首页解析，失败时尝试 hnrss | 技术社区热门条目 |
| IT之家 | `ithome` | 资讯列表解析 | 科技资讯 |
| AIHOT | `aihot` | RSS 订阅 | AI 资讯聚合 |
| OpenAI | `openai-rss` | [官方 RSS](https://openai.com/news/rss.xml) | 官方新闻动态 |

前九个来源复用本项目内的 NewsNow 采集器，OpenAI RSS 在业务适配层单独接入。采集器在本项目运行，直接请求来源页面、接口或订阅，并非依赖 NewsNow 公共 API 返回业务数据。

## 数据流程

```text
公开热榜/资讯/RSS → 获取标题、链接和可选摘要 → 校验 → 持久化 → 关键词匹配 → 选题列表
```

- 目标是从已有榜单和资讯中筛选，不是按关键词搜索整个互联网。
- 标题沿用来源，当前没有用模型生成新的选题标题。
- 每源每轮最多保存前 30 条，不足时按实际数量展示。
- 同源相同外部 ID 或 URL 去重；不同平台的相似内容保留独立来源。
- 默认主题只筛选相关内容，不会把平台全部内容都判为 AI 热点。
- 可选摘要、发表时间可能缺失；不伪造正文、热度或时间。

## 时效与失败

调度尊重用户周期与源的最小间隔。单源总请求预算为 60 秒，最多两个源并发；某个源失败时其他源继续执行。连续三次失败后，重试间隔至少为 30 分钟。

HTTP 成功不等于内容有效。结构异常、无有效标题/链接会记录为失败；合法空榜记为 empty，并取消旧条目的当前在榜标记。失败保留旧数据和最后成功时间，页面明确显示状态。

公开接口、页面结构和 Cookie 可能改变；支持清单表示已配置适配器，实时可用性应在“设置 → 数据来源”中查看。2026-10-15 首轮十源均成功，详情见测试记录；这不是对后续持续可用性的保证。
